# 📝 Daily Journal App

A lightweight and responsive web app to record daily journal entries with mood tracking, tags, and basic sentiment analysis.

## ⚙️ Features
- Add, edit, and delete entries
- Mood and tag support
- Basic sentiment detection (positive, negative, neutral)
- Saves entries using browser localStorage

## 📁 Files
- `index.html` – Structure of the app
- `style.css` – Styling and responsive layout
- `script.js` – App logic and sentiment analysis

## 🚀 How to Use
1. Open `index.html` in your browser.
2. Fill out the journal form and save your entry.
3. View or manage entries below the form.

No installation or setup needed.
